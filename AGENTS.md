## ClickVisual UI Default

For ClickVisual v2 UI work, follow the `kl7sn-ui` compact operational style unless the user explicitly asks for another visual language.

- Preserve the current orange primary direction.
- Prefer dense query/workbench layouts, compact toolbars, split panels, row-list interactions, and one main content container per page.
- Avoid large whitespace cards, duplicate toolbar actions, decorative dashboard blocks, and marketing-style sections.
- Use compact dialogs/dropdowns for short flows. Combine related actions into one entry when possible.
- Use small auto-dismiss toast feedback for transient operation results instead of layout-consuming banners.
- Keep controls readable at desktop operational density and verify both desktop and mobile behavior when changing layout.
